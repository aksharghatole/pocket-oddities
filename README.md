# Pocket Oddities

**[Play the arcade](https://aksharghatole.github.io/pocket-oddities/)**

Pocket Oddities is a collection of original mini-games for quick breaks. Pick a game and play in your browser—no account or download needed.

- Made for phones, and works on desktop too.
- Play with touch, mouse, or keyboard, depending on the game.
- Scores and progress stay on your device.
- Install it from your browser and play offline after the first visit.

### Want to help or try the Android build?

See [how to add a game](docs/ADDING-GAMES.md) and the [roadmap](docs/ROADMAP.md). A test-only Android APK is available from [GitHub Actions](https://github.com/aksharghatole/pocket-oddities/actions).

Run the checks with `npm test`. For the full game list, build steps, and release notes, see the [project reference](README-REFERENCE.md).

The arcade is still growing. The Android APK is for testing and is not a store release.
